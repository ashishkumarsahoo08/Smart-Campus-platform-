ℹ️ About Smart Campus

🏫

Smart Campus Platform

Version 4.0.0 (Enterprise Multi-Tenant Edition)

🏢 Multi-Tenant Data Protection: Each registered institution operates in an isolated data container identified by its unique Institution ID. User data, notices, attendance, and finances are strictly private and never shared.

☁️ Cloud Database: Fully integrated with Supabase PostgreSQL cloud database for persistent synchronization and offline caching.

📱 Hybrid Native App: Powered by Capacitor Android Native runtime with offline persistence and bi-directional web sync.

🤖 AI Intelligence: Integrated with Grok AI Assistant for universal academic and campus assistance.
